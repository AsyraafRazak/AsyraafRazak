### About Me

Software Engineer with experience in developing, maintaining, and integrating enterprise software applications, including **POS systems** and **full-stack web platforms**.

- **Current Role:** Junior Software Engineer at **Cuscapi Innovation Lab Sdn Bhd** — working on POS applications (*QRMenu*, *Kiosk Menu*, *Transight POS*) and middleware integration (*PTI Web API*, *Windows Services*, *Web Services*) using **C#**, **Visual Basic 6 (VB6)**, and **SQL**.
- **Previous Experience:** System Development & Technical Support (MySTEP) and Software Engineer Intern at the **Ministry of Tourism, Arts and Culture (MOTAC)** — building **Laravel**, **Vue.js**, and **Joomla CMS** platforms (*Intranet MOTAC*, *TTMS*, *ATF 2025 Microsite*).
- **Web Studio:** Founder & Web Developer at **[TwoDazzle (twodazzle.com)](https://twodazzle.com/)** — building custom, fast, and responsive websites from scratch.
- **Education:** Bachelor of Software Engineering with Honours (Multimedia System Development), **Universiti Kebangsaan Malaysia (UKM)** — **CGPA 3.92** (*Dean's List Award*).
